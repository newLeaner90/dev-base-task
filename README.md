


# مشروع Idea-Catch Backend 🚀
### 1. فكرة الخدمة الأساسية
منصة تقنية تعمل كواجهة برمجية (API) احترافية مبنية باستخدام **FastAPI** لتسجيل الأفكار فور ورودها. يهدف النظام إلى إدارة وتنظيم "صيد الأفكار" مع ضمان عدم قبول أي فكرة "سطحية" أو ناقصة من خلال:
* **فحص المحتوى:** التحقق آلياً من طول الوصف (بحد أدنى 20 حرفاً).
* **التنظيم الهيكلي:** تحويل الأفكار العفوية إلى بيانات منظمة (**JSON**) جاهزة للمعالجة.
### 2. هيكلة المشروع ومسار التطوير
تم تقسيم المشروع إلى وحدات برمجية لضمان سهولة الصيانة:
1. **النماذج (Schemas):** بناء قواعد البيانات والتحقق باستخدام **Pydantic**.
2. **المنطق البرمجي (Logic):** مساحة مخصصة 

لمعالجة العمليات والتحقق من الشروط.
3. **المحرك الأساسي (Main):** ربط المسارات وتفعيل الخدمات.
### 3. كيفية التشغيل (Deployment)
يمكن تشغيل المشروع بطريقتين:
**أ- التشغيل التقليدي:**
1. تثبيت المكتبات: `pip install -r requirements.txt`
2. تشغيل السيرفر: `uvicorn main:app --reload`
**ب- التشغيل باستخدام Docker (المرحلة النهائية):**
لضمان بيئة عمل موحدة ومنظمة، يتم بناء الصورة وتشغيلها كالتالي:
* **بناء الصورة:** `docker build -t idea-app-image .`
* **التشغيل مع متغيرات البيئة:** `docker run -d -p 8000:8000 --name my-app -e STAGE="production" idea-app-image`
### 4. التوثيق التفاعلي للـ API
بمجرد تشغيل السيرفر، يمكنك تجربة الخدمات والتحقق من جودة إدخال الأفكار عبر الرابط:

* **Swagger UI:** متاح عبر مسارات `/docs` و `/redoc`.
### 5. ملاحظات تقنية
* تم استبعاد ملفات البيئة (venv) عبر `.gitignore` لضمان خفة المستودع.
* تم استخدام مكتبة `os` المدمجة لقراءة متغيرات البيئة (Environment Variables) لتعزيز الأمان والمرونة

## 🚀 كيفية التشغيل (Deployment)
